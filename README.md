# Сайт Александра Шурубкина

Официальный сайт **Александра Дмитриевича Шурубкина** — курс-директора PADI и специалиста гидролаборатории Центра подготовки космонавтов им. Ю. А. Гагарина (Звёздный городок).

## Технологии

- **[Astro](https://astro.build)** — статический генератор: быстрый, бесплатный в хостинге, без базы данных.
- **[Decap CMS](https://decapcms.org)** — веб-админка по адресу `/admin`: новости и семинары добавляются через простую форму в браузере и сохраняются как файлы в git.
- **GitHub Pages + GitHub Actions** — автоматический деплой при каждом изменении в ветке `main`.
- Двуязычность **RU/EN** из коробки.

## Как добавить новость (для владельца сайта)

Вариант 1 — через админку (после настройки OAuth, см. ниже):

1. Открыть `https://<домен>/shourubkin/admin/`
2. Войти через GitHub
3. «Новости» → «Создать» → заполнить форму → «Опубликовать»
4. Сайт пересоберётся и обновится автоматически через 1–2 минуты

Вариант 2 — просто добавить markdown-файл в `src/content/news/`:

```markdown
---
title: "Заголовок новости"
date: 2026-08-01
lang: ru
summary: "Короткое описание"
---

Текст новости в формате Markdown.
```

## Админка

Собственная лёгкая админ-панель: `https://<домен>/shourubkin/admin/`

- **Вход**: пароль — номер телефона (из секретов Actions `MAX_NUMBER` / `TELEGRAM_NUMBER`; формат не важен: +7…, 8…, со скобками или без).
- **Как это работает**: при сборке workflow шифрует GitHub-токен из секрета `ADMIN_PAT` номером телефона (PBKDF2-SHA256, 310 000 итераций + AES-GCM) и кладёт в `admin/auth.json`. Ввод телефона расшифровывает токен в браузере; правки сохраняются коммитами в `main` через GitHub API, после чего сайт пересобирается автоматически.
- **Что можно править**: новости, расписание семинаров и тексты всех страниц (главная, биография, гидролаборатория, курсы, контакты — RU и EN).
- **Секрет `ADMIN_PAT`**: fine-grained personal access token (Settings → Developer settings → Fine-grained tokens) с доступом только к этому репозиторию и правом **Contents: Read and write**. Добавить в Settings → Secrets and variables → Actions.
- Запасной вход: тот же PAT можно ввести в форме входа напрямую.

⚠️ Замечание о безопасности: пароль-телефон — слабый секрет (перебор всех номеров технически возможен, PBKDF2 лишь замедляет его). Токен ограничен одним репозиторием, так что риск — правки этого сайта. Для большей стойкости добавьте к номеру суффикс-слово и используйте его как пароль (тогда задайте его в секрете вместо номера).

## Структура

```
src/
  content/news/      — новости (markdown)
  content/seminars/  — семинары/расписание (markdown)
  content/pages/     — тексты страниц (markdown, редактируются в админке)
  components/        — компоненты и общие страницы (RU/EN)
  pages/             — маршруты RU (/) и EN (/en)
  i18n.ts            — словарь переводов
public/admin/        — админ-панель (вход по паролю-телефону)
.github/workflows/   — автодеплой на GitHub Pages
```

# Как привязать свой домен (например shurubkin.ru)

Инструкция для подключения собственного домена к сайту на GitHub Pages.

## Шаг 1. Настроить DNS у регистратора домена

Зайдите в панель управления DNS вашего регистратора (где куплен домен) и добавьте записи:

**Для корневого домена (`shurubkin.ru`)** — четыре A-записи:

| Тип | Имя | Значение |
|-----|-----|----------|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |

**Для поддомена `www`** — одна CNAME-запись:

| Тип | Имя | Значение |
|-----|-----|----------|
| CNAME | www | leonidy431.github.io |

DNS-изменения вступают в силу от нескольких минут до 24 часов.

## Шаг 2. Указать домен в настройках GitHub

1. Откройте репозиторий → **Settings** → **Pages**
2. В поле **Custom domain** введите `shurubkin.ru` и нажмите **Save**
3. Дождитесь, пока GitHub проверит DNS (появится зелёная галочка)
4. Поставьте галочку **Enforce HTTPS** (появится после успешной проверки DNS; сертификат выпускается автоматически и бесплатно)

GitHub сам создаст файл `CNAME` в ветке. Чтобы он не стирался при следующем деплое, добавьте его и в репозиторий: создайте файл `public/CNAME` с одной строкой:

```
shurubkin.ru
```

## Шаг 3. Обновить конфигурацию сайта

Сейчас сайт собирается под адрес `https://leonidy431.github.io/shourubkin/`. Для своего домена нужно поменять два значения в `astro.config.mjs`:

```js
export default defineConfig({
  site: 'https://shurubkin.ru',   // было: https://leonidy431.github.io
  base: '/',                      // было: /shourubkin
  ...
});
```

И одно значение в `public/admin/config.yml` (путь к загруженным картинкам):

```yaml
public_folder: "/uploads"   # было: /shourubkin/uploads
```

После коммита этих изменений в `main` сайт автоматически пересоберётся и откроется по адресу `https://shurubkin.ru`.

## Шаг 4. Проверка

- `https://shurubkin.ru` — открывается сайт, в адресной строке замок (HTTPS)
- `https://www.shurubkin.ru` — перенаправляет на основной домен
- Старый адрес `https://leonidy431.github.io/shourubkin/` продолжит перенаправлять на новый домен

## Частые проблемы

- **«Domain is not properly configured»** — DNS ещё не обновился; подождите и нажмите Save ещё раз.
- **Сайт открывается без стилей** — не изменён `base` в `astro.config.mjs` (Шаг 3).
- **Enforce HTTPS неактивна** — сертификат ещё выпускается, обычно до часа после проверки DNS.
- **Домен «отвязывается» после деплоя** — нет файла `public/CNAME` в репозитории (Шаг 2).
